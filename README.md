# 📊 Dashboard de Salários na Área de Dados

Este projeto consiste em um **dashboard interativo** desenvolvido em **Python**, utilizando **Streamlit**, **Pandas** e **Plotly Express**, com foco na análise e visualização de **salários na área de dados**.

A aplicação permite:  
- 🔎 Filtrar informações de forma dinâmica  
- 📊 Explorar métricas relevantes da base  
- 📈 Gerar gráficos interativos e personalizáveis  

O principal objetivo é oferecer uma **ferramenta intuitiva e acessível** para facilitar a análise exploratória, identificar **padrões e tendências salariais** e apoiar a **tomada de decisão** com base em dados.

---

## 🚀 Tecnologias Utilizadas
- **Python** – Linguagem principal do projeto  
- **Pandas** – Manipulação e tratamento de dados  
- **Plotly Express** – Criação de gráficos interativos  
- **Streamlit** – Desenvolvimento do dashboard web  
- **NumPy** – Operações matemáticas e estruturais  
- **Jupyter Notebook / Google Colab** – Exploração inicial dos dados
